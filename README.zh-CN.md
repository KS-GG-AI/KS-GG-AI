## 我在做什么

我构建那些从外部看应当简单、但背后需要大量协作的产品部分：清晰的界面、可连接的工具和可重复的工作流。大部分工作位于产品思考、自动化和系统设计的交汇处。

- **产品界面** — 让下一步一目了然的界面和流程
- **连接的工作** — 通过 API、集成和自动化减少重复交接
- **为变化而构建** — 易于测试、调整和维护的小型基础
