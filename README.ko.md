## 안녕하세요, KS-GG-AI입니다 👋

막연한 아이디어를 쓸모 있고 세심한 소프트웨어로 바꾸는 일을 좋아합니다. 탄탄한 기반, 명확한 경험, 그리고 도구를 더 기분 좋게 만드는 작은 디테일을 중요하게 생각합니다.

- ✦ **태도** — 호기심은 기본으로, 필요할 때는 실용적으로
- ◌ **관심사** — 소프트웨어 제작, 자동화, 시스템, 사람 친화적인 도구
- ↗ **방식** — 작게 시작하고, 빠르게 배우고, 꾸준히 개선하기
