## 我在构建什么

我构建那些对使用者而言应当简单、即使背后工作并不简单的产品部分：清晰的界面、相互连接的工具和可重复的工作流。大部分工作位于产品思考、自动化和系统设计的交汇处。

- **产品体验** — 让下一步一目了然的界面和流程
- **连接的流程** — 通过 API、集成和自动化减少重复交接
- **可持续演进** — 易于测试、调整和维护的小型基础
